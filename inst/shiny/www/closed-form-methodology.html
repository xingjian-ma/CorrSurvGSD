Closed-Form Methodology for Correlated Group Sequential Designs

library(CorrSurvGSD)

Scope

  • CorrSurvGSD evaluates correlated PFS and OS group sequential designs under the Fleischer model.
  • The first part of this vignette is an interface walkthrough for the R pipeline and the bundled Shiny application.
  • The later sections document the statistical model, closed-form calculations, boundaries, power, and optional simulation in implementation order.
  • The pipeline returns theoretical results and can optionally append Monte Carlo results without changing the theoretical calculations.

Pipeline example

The public interface is run_pipeline(). It validates the design, derives the calendar cutoffs and moments, constructs the joint correlation matrix, and calculates power.

state <- run_pipeline(
  n_T = 100,
  n_C = 100,
  d_PFS_vec = c(50, 100),
  v_vec = c(200 / 12),
  median_PFS_C = log(2) / 0.25,
  median_OS_C = log(2) / 0.10,
  HR_PFS = 0.8,
  HR_OS = 0.85,
  alpha_spending_PFS = "OF",
  alpha_spending_OS = "Pocock",
  efficacy_looks = list(PFS = c(1, 2), OS = c(1, 2)),
  futility_looks = list(PFS = 1, OS = integer(0)),
  hierarchy_order = c(primary = "PFS", secondary = "OS"),
  integration_seed = 777
)

After installing the package with the optional shiny dependency available, launch the bundled application with run_app(). This chunk is intentionally unevaluated because shiny::runApp() starts a blocking interactive session.

CorrSurvGSD::run_app()

In the application, enter the same sample sizes, accrual schedule, control medians, treatment HRs, alpha-spending choices, look schedules, hierarchy, and seed values used in the R example. Select Run analysis to validate the input and calculate the pipeline. The Results page then provides the Design summary, Boundaries, and Power tabs. Fleischer model and observed quantities

For treatment or control arm \(g\), let the latent progression and death times be independent exponential variables:

\[\begin{equation*} E_{1g} \sim \operatorname{Exp}(\lambda_{1,g}), \qquad E_{2g} \sim \operatorname{Exp}(\lambda_{2,g}), \qquad E_{1g} \perp E_{2g}. \end{equation*}\]

PFS is the first latent event and OS is the death time. Therefore the PFS hazard is \(\Lambda_g = \lambda_{1,g} + \lambda_{2,g}\).

\[\begin{equation*} T_g^{PFS} = \min(E_{1g}, E_{2g}), \qquad T_g^{OS} = E_{2g}, \qquad \Lambda_g = \lambda_{1,g} + \lambda_{2,g}. \end{equation*}\]

For total sample size \(n=n_T+n_C\), the enrollment time \(U\) has density \(p_i=v_i/n\) on accrual segment \((t_{i-1},t_i]\). At calendar cutoff \(A\), set \(a=(A-U)_+\), \(\delta^k(A)=\mathbf{1}(T^k\le a)\), and \(\widetilde T^k(A)=\min(T^k,a)\). These definitions include administrative censoring and make subjects enrolled after \(A\) contribute zero follow-up.

Model inputs and pipeline state

  • The design requires treatment and control sample sizes, accrual rates, target PFS event counts, control PFS and OS medians, and either treatment medians or endpoint-specific hazard ratios. The unused treatment input pair defaults to NULL.
  • efficacy_looks and futility_looks default to NULL. This performs efficacy analysis only at the final look and disables futility analysis for both endpoints.
  • When configured, futility_looks must contain strictly increasing integer looks before the final look, so every futility look satisfies look < L.
  • hierarchy_order specifies whether PFS or OS is the primary gatekeeping endpoint.
  • The returned trial_state stores validated design quantities in state$design, numerical settings in state$options, and theoretical results in state$theoretical_results.

Module 1: calendar cutoffs

  • For each PFS event look, the pipeline solves for the expected calendar cutoff A_l.
\[\begin{equation*} n_T m_{\delta_l^{PFS}}^{(T)}(A_l) + n_C m_{\delta_l^{PFS}}^{(C)}(A_l) = d_l^{PFS}. \end{equation*}\]
  • The monotone event-count equation is solved numerically using tol. The resulting A_vec is saved in state$design.

Module 2: per-subject moments

  • For a subject enrolled at time U, define B = min(A, R) and integrate over the piecewise-uniform enrollment distribution.
  • For endpoint hazard mu, the single-look event and truncated-time means are obtained from the closed-form integrals I_1 through I_5. The I_2 and I_3 terms provide the first and second polynomial truncated-time integrals used by the cross-look moment calculations.
  • PFS/OS cross-look products use the ordering of A_1 and A_2 and the Fleischer latent hazards. The resulting single-look and cross-look moments are stored in state$moments.
  • Expected OS event counts are derived from the single-look means and saved as state$design$d_OS_vec.

For a segment \((\tau_1,\tau_2]\), the required exponential integrals are

\[\begin{equation*} \begin{aligned} i_1(\tau_1,\tau_2,A,\mu) &= \tau_2-\tau_1, \\ i_2(\tau_1,\tau_2,A,\mu) &= \frac{(\tau_2-\tau_1)(2A-\tau_1-\tau_2)}{2}, \\ i_3(\tau_1,\tau_2,A,\mu) &= \frac{(\tau_2-\tau_1)\left[3A^2-3A(\tau_1+\tau_2)+\tau_1^2+\tau_1\tau_2+\tau_2^2\right]}{3}, \\ i_4(\tau_1,\tau_2,A,\mu) &= \frac{e^{-\mu(A-\tau_2)}-e^{-\mu(A-\tau_1)}}{\mu}, \\ i_5(\tau_1,\tau_2,A,\mu) &= \frac{e^{-\mu(A-\tau_2)}(A-\tau_2+1/\mu) -e^{-\mu(A-\tau_1)}(A-\tau_1+1/\mu)}{\mu}. \end{aligned} \end{equation*}\]

Writing \(B=\min(A,R)\) and letting \(b\) be its segment index, the implementation forms the weighted sum

\[\begin{equation*} I_j(A,B,b,\mu)=\sum_{i=1}^{b-1}p_i i_j(t_{i-1},t_i,A,\mu) +p_b i_j(t_{b-1},B,A,\mu). \end{equation*}\]

For endpoint hazard \(\mu\), the four single-look product means are

\[\begin{equation*} \begin{aligned} m_\delta &= I_1-I_4, & m_{\widetilde T} &= \frac{I_1-I_4}{\mu}, \\ m_{\widetilde T^2} &= \frac{2}{\mu^2}(I_1-I_4-\mu I_5), & m_{\delta\widetilde T} &= \frac{I_1-I_4}{\mu}-I_5. \end{aligned} \end{equation*}\]

The corresponding covariance is obtained by subtracting the product of the two single-look means. For PFS look 1 and OS look 2, let \(a_j=A_j-U\), \(\lambda_1=\lambda_{1,g}\), \(\lambda_2=\lambda_{2,g}\), \(\Lambda=\lambda_1+\lambda_2\), and \(A_\star=(\lambda_1A_1+\lambda_2A_2)/\Lambda\). In the formulas below, \(I_j(A,\mu)\) abbreviates \(I_j(A,B,b,\mu)\) with \(B=\min(A_1,A_2,R)\).

When \(A_1\le A_2\), the four unconditional cross-look product means are

\[\begin{equation*} \begin{aligned} m_{\delta_1\delta_2} &=I_1(A_1)-I_4(A_2,\lambda_2)-I_4(A_1,\Lambda) +I_4(A_\star,\Lambda), \\ m_{\delta_1\widetilde T_2} &=\frac{I_1(A_1)-I_4(A_2,\lambda_2)}{\lambda_2} -I_5(A_1,\Lambda) -\frac{I_4(A_1,\Lambda)-I_4(A_\star,\Lambda)}{\lambda_2}, \\ m_{\widetilde T_1\delta_2} &=\frac{I_1(A_1)-I_4(A_1,\Lambda)}{\Lambda} -\frac{I_4(A_2,\lambda_2)-I_4(A_\star,\Lambda)}{\lambda_1}, \\ m_{\widetilde T_1\widetilde T_2} &=\frac{I_1(A_1)}{\Lambda^2} -\frac{I_5(A_1,\Lambda)}{\Lambda} -\frac{I_4(A_1,\Lambda)}{\Lambda^2} \\ &\quad+\frac{I_1(A_1)-I_4(A_1,\Lambda)}{\lambda_2\Lambda} -\frac{I_4(A_2,\lambda_2)}{\lambda_1\lambda_2} +\frac{I_4(A_\star,\Lambda)}{\lambda_1\lambda_2}. \end{aligned} \end{equation*}\]

When \(A_1>A_2\), the integration domain is truncated at \(A_2\) and the corresponding four means are

\[\begin{equation*} \begin{aligned} m_{\delta_1\delta_2} &=I_1(A_2)-I_4(A_2,\lambda_2), \\ m_{\delta_1\widetilde T_2} &=\frac{I_1(A_2)-I_4(A_2,\lambda_2)}{\lambda_2} -e^{-\Lambda(A_1-A_2)}I_5(A_2,\Lambda), \\ m_{\widetilde T_1\delta_2} &=\frac{I_1(A_2)-I_4(A_2,\Lambda)}{\Lambda} -\frac{I_4(A_2,\lambda_2)-I_4(A_2,\Lambda)}{\lambda_1}, \\ m_{\widetilde T_1\widetilde T_2} &=\frac{I_1(A_2)-I_4(A_2,\Lambda)}{\Lambda^2} -\frac{e^{-\Lambda(A_1-A_2)}I_5(A_2,\Lambda)}{\Lambda} \\ &\quad+\frac{I_1(A_2)-I_4(A_2,\Lambda)}{\lambda_2\Lambda} -\frac{I_4(A_2,\lambda_2)-I_4(A_2,\Lambda)} {\lambda_1\lambda_2}. \end{aligned} \end{equation*}\]

Module 3: joint correlation matrix

  • The log hazard-ratio variances and PFS/OS cross-endpoint covariances are calculated with the Delta method.
\[\begin{equation*} \operatorname{Var}(\hat{\theta}_l^k) = \sum_{g \in \{T,C\}} \frac{1}{n_g} \nabla g^\top \Sigma_{k,l}^{(g)} \nabla g. \end{equation*}\]
  • Within an endpoint, canonical group-sequential information gives rho(l_1, l_2) = sqrt(d_min / d_max).
  • Across endpoints, the covariance is standardized by the corresponding marginal variances. The combined (2L) x (2L) matrix is stored with PFS looks first and OS looks second.

For endpoint \(k\) and look \(\ell\), define \(X_{g,k,\ell}=(\delta^k_\ell,\widetilde T^k_\ell)^\top\) and let \(\Sigma_{g,k,\ell}\) be its per-subject covariance matrix. The log-rank log-hazard-ratio map is \(h(x_1,x_2)=\log(x_1)-\log(x_2)\), with gradient

\[\begin{equation*} \nabla h_{g,k,\ell} = \left(\frac{1}{m_{\delta^k_\ell}^{(g)}}, -\frac{1}{m_{\widetilde T^k_\ell}^{(g)}}\right)^\top. \end{equation*}\]

The Delta method gives

\[\begin{equation*} \operatorname{Var}(\widehat{\theta}^k_\ell) =\sum_{g\in\{T,C\}}\frac{1}{n_g} \nabla h_{g,k,\ell}^{\top} \Sigma_{g,k,\ell} \nabla h_{g,k,\ell}. \end{equation*}\]

For PFS look \(\ell_1\) and OS look \(\ell_2\), the cross-endpoint covariance uses the corresponding \(2\times2\) cross-look covariance block:

\[\begin{equation*} \operatorname{Cov}(\widehat{\theta}^{PFS}_{\ell_1}, \widehat{\theta}^{OS}_{\ell_2}) =\sum_{g\in\{T,C\}}\frac{1}{n_g} \nabla h_{g,PFS,\ell_1}^{\top} \Sigma_{g,PFS,OS,\ell_1,\ell_2} \nabla h_{g,OS,\ell_2}. \end{equation*}\]

Within an endpoint, the canonical group-sequential correlation is

\[\begin{equation*} \rho^k_{\ell_1,\ell_2} = \sqrt{\frac{d_{\min(\ell_1,\ell_2)}^k}{d_{\max(\ell_1,\ell_2)}^k}}. \end{equation*}\]

Across endpoints, the covariance is standardized by the two marginal standard deviations. The result is a \((2L)\times(2L)\) matrix ordered as PFS looks first and OS looks second.

Module 4: boundaries and theoretical power

  • The mean drift at look l for endpoint k is
\[\begin{equation*} \theta_l^k = -\log(HR_k)\sqrt{\frac{d_l^k r}{(1+r)^2}}, \qquad r = \frac{n_T}{n_C}. \end{equation*}\]
  • Efficacy boundaries are calculated from the selected alpha-spending family. Configured futility boundaries are calculated from the corresponding futility hazard ratios.
  • The primary Z-scale boundary is retained in state$design$boundary. Finite boundaries are also converted to HR and one-sided p scales.
\[\begin{equation*} s_l = \sqrt{\frac{d_l r}{(1+r)^2}}, \qquad HR_l = \exp\left(-\frac{Z_l}{s_l}\right), \qquad p_l = 1 - \Phi(Z_l). \end{equation*}\]
  • state$design$boundary_HR and state$design$boundary_p use NA_real_ for unconfigured boundaries, while Z-scale -Inf and Inf remain available for power and simulation logic.
  • marginal_power is calculated from first efficacy-crossing regions using multivariate normal integration and integration_seed.
  • Joint power follows hierarchy_order: the primary endpoint must cross its efficacy boundary before the secondary endpoint is evaluated. The mutually exclusive crossing probabilities are stored in joint_power_matrix and sum to joint_power.

For endpoint \(k\), the mean Z-score drift at look \(\ell\) is

\[\begin{equation*} \theta_\ell^k=-\log(HR_k) \sqrt{\frac{d_\ell^k r}{(1+r)^2}}, \qquad r=\frac{n_T}{n_C}. \end{equation*}\]

The selected alpha-spending family supplies finite efficacy boundaries at the configured efficacy looks. Futility boundaries are derived from the configured futility hazard ratios. With \(s_\ell=\sqrt{\frac{d_\ell r}{(1+r)^2}}\), a finite Z boundary converts as

\[\begin{equation*} HR_\ell=\exp\left(-\frac{Z_\ell}{s_\ell}\right), \qquad p_\ell=1-\Phi(Z_\ell). \end{equation*}\]

Unconfigured futility and efficacy entries remain \(-\infty\) and \(+\infty\) on the Z scale and are represented by NA_real_ on the HR and p scales.

For candidate efficacy look \(\ell\), the marginal incremental power integrates the first-crossing region

\[\begin{equation*} \Pr\left( c_j\le Z_j\le a_j,\ j<\ell,\quad Z_\ell\ge a_\ell \right), \end{equation*}\]

where \(c_j\) are futility bounds and \(a_j\) are earlier efficacy bounds. The cumulative marginal power is the sum of incremental probabilities across looks. For gatekeeping, the primary endpoint must cross first; the secondary endpoint is then restricted to crossings at the same or a later look. These mutually exclusive probabilities populate joint_power_matrix and sum to joint_power.

Module 5: optional simulation

  • When simulation = TRUE, the package generates trial-level Fleischer event times, enrollment times, event counts, person-time, and Z statistics.
  • Simulation derives each calendar cutoff from the simulated PFS event times and calculates OS statistics from the simulated OS event times. It does not modify the closed-form results.
  • Invalid replicates with zero events or zero person-time are regenerated up to the internal attempt limit.
  • Empirical means, correlations, marginal power, and joint power are stored in state$empirical_results. The simulation seed remains in state$options$simulation_seed.

Reproducibility

  • Set integration_seed to control numerical multivariate-normal integration.
  • Set simulation_seed and simulation = TRUE to obtain reproducible Monte Carlo summaries.
  • The returned trial_state preserves the validated design, options, and theoretical results for downstream reporting.
